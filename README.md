# Microservicios y APIs Escalables

Este repositorio contiene apuntes, prácticas y documentación relacionada con la materia Microservicios y APIs Escalables, cuyo objetivo es comprender y aplicar conceptos modernos de desarrollo backend con Java, arquitectura de software, desarrollo de APIs REST y diseño de microservicios con Spring.

- [Módulo 2: Arquitectura de Software](#módulo-2-arquitectura-de-software)
- [Módulo 3: Spring y Spring Boot](#módulo-3-spring-y-spring-boot)
- [Módulo 4: Persistencia con JPA](#módulo-4-persistencia-con-jpa)

## Módulo 1: Java, POO y Maven

    Principios de Programación Orientada a Objetos (POO) en Java

    Introducción a Maven: gestión de dependencias y ciclo de vida del proyecto

    Estructura de pom.xml, uso de repositorios y plugins

    Introducción al uso de frameworks en el desarrollo Java

## Módulo 2: Arquitectura de Software

    Tipos de arquitecturas: TCP/IP, arquitectura Broker, Event-Bus

    Capas de una arquitectura empresarial:

        Presentación

        Negocio

        Acceso a datos

        Integración

        Seguridad

## Módulo 3: Spring Framework

    Introducción a Spring y sus módulos principales

    Spring Boot: inicialización y configuración automática de proyectos

    Spring Core e Inversión de Control (IoC)

    Principios de Inyección de Dependencias (DI)

## Módulo 4: Persistencia de Datos

    Patrón DAO (Data Access Object)

    JPA (Java Persistence API) y ORM

    Uso de Spring Data JPA para simplificar el acceso a datos

    Manejo de transacciones y consultas (queries personalizadas y derivadas)

## Módulo 5: APIs REST

    Definición y funcionamiento de una API

    API REST: conceptos de HTTP y JSON

    Comparación REST vs SOAP

    Desarrollo de controladores con Spring MVC

    Uso de DTOs (Data Transfer Objects) y anotaciones como @RequestMapping, @GetMapping, etc.

## Módulo 6: Microservicios

    Qué es un microservicio y comparación con arquitecturas monolíticas

    Principales desafíos de una arquitectura de microservicios

    Herramientas habilitadoras: Spring Boot + Spring Cloud

    Configuración de Eureka Server para registro y descubrimiento de servicios

    Comunicación entre microservicios mediante Feign Clients
